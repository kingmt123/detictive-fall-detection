# 技术可行性与尽调说明

## 1. 交付范围

本材料对应“面向低算力平台的实时跌倒检测”最终七头运行包。系统输入为普通 RGB 视频，输出人体跟踪编号、候选跌倒时间段、七个成员分类头的原始 logits 与均值融合后的风险分数；最终二值化由 sigmoid 在融合后执行。该包以 `MANIFEST.json` 约束模型、推理代码与运行依赖的一致性。

## 2. 技术路线与可行性

系统采用“视频输入—人体姿态估计与跟踪—双尺度时序编码—七头集成融合—可解释告警输出”的流水线。姿态序列降低了背景、服饰与光照的直接干扰；双尺度时序编码兼顾短时失衡动作与持续倒地状态；七个独立成员输出先取均值、再经 sigmoid 形成稳定风险分数。运行包内保留了可复核清单，便于部署前检查模型与代码文件是否被替换。

## 3. 证据与验证边界

随包提供的验证证据为 OF-Syn 验证集 1,200 段：mAP 75.208%、P@R90 77.907%、P@R95 72.509%。最终运行包规模为 4.053M 参数、FP32 权重约 15.46 MiB；全流程基准记录为 3,960 帧平均 15.45 ms/帧。另附端到端烟测 JSON：160 帧视频均完成处理，并输出可追溯候选区间。上述指标与烟测记录用于说明当前交付包的推理效果和可运行性，不外推为未复核场景的保证。

## 4. 数据、行业知识与第三方组件来源

训练和验证说明引用 OmniFall 标注与 OF-Syn 合成视频；展示视频素材使用 UR Fall Detection Dataset（URFD）的公开视频。人体姿态估计采用 Ultralytics YOLO Pose，深度学习运行框架为 PyTorch。数据集、框架、预训练权重及其衍生使用均须遵循各来源发布的许可、署名与再分发要求；本辅助包不重新分发原始数据集或第三方预训练权重。

## 5. 使用与合规建议

系统用于跌倒风险辅助识别，应由人工复核后采取处置措施，不应用作医疗诊断或唯一决策依据。实际部署应遵守视频采集、个人信息保护与场景管理要求，实施最小必要采集、访问控制、留存期限和告警审计。对人群、机位、光照、遮挡等变化，建议在目标场景完成独立测试后再上线。
