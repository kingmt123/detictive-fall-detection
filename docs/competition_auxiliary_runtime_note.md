# 运行与复核说明

1. 将最终运行包保持在 `deploy/final_model` 的原有目录结构中。
2. 以 `MANIFEST.json` 中记录的大小和 SHA-256 校验模型、推理脚本与依赖文件，确认交付完整性。
3. 执行运行包 README 中的推理命令；输出应包含协议名、帧级风险分数和候选时间段。
4. `final_model_smoke.json` 是对 `fall-01-cam1.mp4` 的端到端烟测记录：160 帧已处理，候选区间为 0.7667 s 至 4.7667 s，风险分数为 0.17800459265708923。
5. 视频中的人体框、17 点骨架、跟踪编号、七头 logits 和融合风险均来自同一条检测流水线，便于核对展示与交付逻辑的一致性。

复核时请使用目标场景的授权视频，并在部署前重新进行场景适配测试。
